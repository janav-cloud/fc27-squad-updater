Frequently Asked Questions about EA SPORTS FC Squad Updates

How do I import squad files in EA SPORTS FC 27 on PC?

Download the latest official Squads save file (e.g., Squads20261006000000). Press Win + R and navigate to %USERPROFILE%\AppData\Local\EA SPORTS FC 27\settings. Paste the file directly there with no file extension. Then launch EA SPORTS FC 27, navigate to Settings / Customize, select Profile, and choose Load Squads.

How can I update rosters on PlayStation 5 and PS4?

Format a USB drive to FAT32 or exFAT. Use Apollo Save Tool or Save Wizard to decrypt and resign the squad save to your PSN Account ID. Transfer the save via PS5 Settings > Saved Data > USB Drive to Console Storage.

Does EA SPORTS FC Squad Updater support FC 26, FC 25, and FC 24?

Yes, use the title dropdown selector to switch between EA SPORTS FC 27, EA SPORTS FC 26, EA SPORTS FC 25, and EA SPORTS FC 24 for all gaming platforms.

What is the EA RefPack decompressor?

EA's official CDN sends squad rosters compressed with RefPack (QFS LZ). This tool includes a built-in client-side JavaScript RefPack decompressor and save container packaging pipeline.
